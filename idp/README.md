# IDP source code

This directory contains the source code of the Internal Developer Platform:

- [`backend/`](backend/) contains the current Go service, embedded HTML UI,
  database migrations, infrastructure modules, fixtures, and operator scripts.
- [`frontend/`](frontend/) is reserved for a future independently built IDP
  frontend.

Demo workloads are intentionally kept outside the product source tree under
[`demo-apps/`](../demo-apps/).
