# Documentation archive

Files placed here are historical and non-normative. Each archived file must name the current artifact that supersedes it when one exists.

Consolidated predecessors that have passed semantic reconciliation live under `consolidated/`. Original planning artifacts live under `planning/`. Current definitions must remain outside this directory; archive files may provide provenance but never own current behavior.

The approved destination and prerequisites for each archive move are defined in [the documentation migration map](../MIGRATION_PLAN.md).

Completed comparison results are recorded in [documentation reconciliation](../implementation/documentation-reconciliation.md).
